# 🎭 MAR PD Bot - Complete Telegram Bot

A fully-featured Telegram bot with AI learning, gaming system, manual payments (Bkash/Nagad), and complete admin controls.

## ✨ Features

### 🤖 AI System
- Learns from user conversations
- No external APIs required
- Context-aware responses
- Bangla language support

### 🎮 Gaming System
- 20+ different games
- Points and rewards system
- Leaderboards and rankings
- Daily bonuses and streaks

### 💰 Economy System
- Virtual points system
- Manual Bkash/Nagad payments
- Withdrawal system
- Point transfers between users

### 🛒 Virtual Shop
- VIP packages
- Boosts and power-ups
- Cosmetic items
- Game items

### 👮 Admin System
- Complete user management
- Manual payment verification
- Analytics and reports
- Broadcast system
- Backup and restore

### 📊 Analytics
- Real-time statistics
- User growth tracking
- Revenue reports
- Game popularity analytics

### 🔒 Security
- Rate limiting
- Spam detection
- CAPTCHA system
- Security logs
